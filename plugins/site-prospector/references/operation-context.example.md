# Operation context (example)

Copy this to `adam-operation-context.md` (gitignored) and fill it in. The skill
reads that file; this one is only the shape.

Named for its author in the real copy, so keep the filename you choose stable
and reference it from SKILL.md.

## Identity
- Public handle / persona used for all published work
- Commit email (use a forge noreply address, never a personal mailbox)

## Territory
- Region and the counties or towns you actually cover
- Your state's business-registry feeds. Most states publish three useful ones:
  daily new-entity filings, a fictitious-name/DBA feed, and periodic licensee
  downloads from the trade licensing board. Find your state's equivalents and
  note the URLs and any SFTP credentials here.

## Stack
- Host and plan, plus the real quota that bites (credits, build minutes, seats)
- Deploy command and the publish directory
- Lead tracker URL, and where its credentials live (a password manager, NOT here)

## Live work
- One line per client: slug, trade, area, live URL, status
- Keep this file out of version control. It is the single place identities live.

## Pricing
- Your tiers, setup fees, and what is included at each
